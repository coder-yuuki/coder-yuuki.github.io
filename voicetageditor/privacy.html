VoiceTagEditor サポートへ

プライバシーポリシー

制定：2025年12月17日　最終改定：2026年11月21日

このページでは、VoiceTagEditor（以下「本アプリ」）で扱う情報と、その扱い方を説明します。

かんたんにまとめると

  • 音声ファイルやタグ情報はすべてお使いのパソコン内だけで処理します。
  • 解析・変換・編集したデータを開発者や第三者へ送信することはありません。
  • 広告、アクセス解析、行動の追跡（トラッキング）は行いません。

1. 提供者

本アプリは、個人開発者の野久知 優希（以下「開発者」）が提供しています。

2. 本アプリが扱う情報

本アプリは、タグの編集や音声ファイルの書き出しに必要な範囲で、次の情報をパソコン内で取り扱います。

  • 利用者が選択、またはドラッグ＆ドロップした音声ファイル・画像ファイル・フォルダのパス
  • 音声ファイルに含まれるメタデータ（タイトル、アーティスト、アルバム、カバーアートなど）

3. 外部への送信（通信）

  • 本アプリは、解析・変換・編集したデータを開発者や第三者へ自動送信しません。
  • 音声の解析・変換処理のために FFmpeg を外部プロセスとして呼び出します（FFmpeg は本アプリに同梱していません）。
  • FFmpeg が見つからない場合に限り、初回に FFmpeg の配布元（macOS：ffmpeg.martin-riedl.de、Windows：github.com）から FFmpeg 本体をダウンロードします。この通信で音声ファイルやタグ情報が送信されることはありません（一般的な HTTP 通信と同様に、IP アドレスやアプリ名・バージョンを含む User-Agent は配布元に届きます）。なお、ダウンロードに失敗した場合は、お使いの OS のパッケージ管理ツール（Homebrew / winget / Chocolatey / Scoop）を通じて取得を試みることがあります。
  • アップデートの確認のため、本アプリの更新情報を取得する通信を行います。

4. パソコン内への保存と削除

本アプリは利便性のため、次の情報をパソコン内に保存する場合があります。

  • オンボーディングの表示状態：WebView のローカルストレージ（キー：vte_onboarding_seen_v1）
  • 自動ダウンロードした FFmpeg：macOS は ~/Library/Application Support/com.noguchiyuuki.voicetageditor/ffmpeg/、Windows は %LOCALAPPDATA%\com.noguchiyuuki.voicetageditor\ffmpeg\
  • カバー画像の一時キャッシュ：パソコン内のキャッシュフォルダ（例：$HOME/.cache/VoiceTagEditor/album_art/、環境により USERPROFILE 配下）

オンボーディングの表示状態は WebView のローカルストレージを削除することで初期化できます。自動ダウンロードした FFmpeg やカバー画像の一時キャッシュは、上記のフォルダごと削除して構いません（FFmpeg は必要になれば再度ダウンロードされます）。

5. 広告・アクセス解析

本アプリは、広告の表示、アクセス解析ツール、行動の追跡（トラッキング）を使っていません。今後この方針を変える場合は、このページを更新してお知らせします。

6. 第三者ソフトウェア

本アプリは Tauri や Preact などのオープンソースソフトウェアを利用しています。詳細はリポジトリの THIRD-PARTY-NOTICES.md をご覧ください。

7. このポリシーの変更

機能の追加などに合わせて、このポリシーを見直すことがあります。大切な変更がある場合は、リポジトリやこのページでお知らせします。

8. お問い合わせ先

このポリシーについてのご質問やご要望は、VoiceTagEditor の GitHub Issues からご連絡ください。

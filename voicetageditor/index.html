無料デスクトップアプリ（macOS / Windows）

VoiceTagEditor

音声作品・ボイスドラマのタグ、カバー画像、トラック番号をかんたんに整えて保存できるパソコン用アプリです。WAV・MP3・FLAC・M4Aに対応し、すべてお使いのパソコン内だけで処理します。

インストール方法

macOS（Apple Silicon）

上のボタンから .dmg ファイルをダウンロードして開き、VoiceTagEditor を Applications フォルダへドラッグして入れます。

Windows（64-bit）

上のボタンから -setup.exe（または .msi）をダウンロードし、ダブルクリックして画面の案内に沿ってインストールします。

初回起動時にセキュリティ警告が出た場合や、音声エンジン（FFmpeg）の自動準備については、下の「よくある質問」をご確認ください。

かんたん4ステップの使い方

  1. 音声を選ぶ

    音声ファイルや作品フォルダをドラッグ＆ドロップします。フォルダ内のカバー画像も自動で読み込みます。

  2. 作品情報を入力する

    作品名・サークル名・発売日・タグ・カバー画像を設定します。

  3. トラックを確認・整理する

    ミニプレイヤーで中身を試聴しながら、タイトル・トラック番号・声優を整理します。

  4. 保存する

    保存先フォルダを選ぶだけ。元のファイルを残したまま、サークル名 / 作品名 フォルダへ安全に書き出します。

初めてでも迷わない「かんたんモード」と、1画面で素早く編集できる「詳細モード」をいつでも切り替えられます。

できること

2つの編集モード

ガイド付きで順番に進められる「かんたんモード」と、全項目を一覧で素早く編集できる「詳細モード」を切り替えられます。

ミニプレイヤーで試聴

トラック一覧からワンクリックで再生できます。シークバー、±10秒スキップ、前後トラック移動にも対応しています。

トラック整理・タイトル一括整形

ドラッグ＆ドロップやボタンで並び替え、ディスクごとの連番振り直し、先頭の番号・記号除去や一括置換ができます。

声優の一括入力とコピー

全トラックへの一括適用、先頭トラックからのコピー、上のトラックからのコピーで手間を減らせます。

4言語の画面表示

日本語・English・한국어・繁體中文（台灣）に対応しています。ヘッダーからいつでも切り替えられます。

完全ローカル処理で安心

Undo / Redo、前回の保存先記憶、保存後の自動デコード検証を備えています。音声やタグを外部へ送信しません。

対応形式：WAV / MP3 / FLAC / M4A

よくある質問

macOSで「開発元を確認できない」などの警告が出て開けません

Finderの「アプリケーション」フォルダで VoiceTagEditor を右クリックし、「開く」を選んでください。表示されたダイアログでもう一度「開く」をクリックすると起動できます。

それでも開けない場合は、ターミナルで次のコマンドを実行してください。

xattr -dr com.apple.quarantine /Applications/VoiceTagEditor.app
Windowsで「WindowsによってPCが保護されました」と表示されます

警告画面の「詳細情報」をクリックし、続けて「実行」をクリックしてインストールを進めてください。

初回起動時にFFmpegの準備が始まりますか？

VoiceTagEditorは音声の解析・保存にFFmpegを使用します（アプリ本体には同梱していません）。初回起動時にFFmpegが見つからない場合は、アプリが自動でダウンロードして準備します（初回のみ。macOS 約55MB / Windows 約115MB）。Homebrewやwingetなどの事前準備は不要です。

保存先はアプリ専用のデータフォルダ（macOS：~/Library/Application Support/com.noguchiyuuki.voicetageditor/ffmpeg/、Windows：%LOCALAPPDATA%\com.noguchiyuuki.voicetageditor\ffmpeg\）で、システムの設定（PATHなど）は変更しません。

ダウンロードするのはバージョン固定のビルド（FFmpeg 9.1：macOSは ffmpeg.martin-riedl.de、Windowsは gyan.dev）で、SHA256で改ざんがないことを確認してから使います。

すでにFFmpegがインストールされている場合はそちらをそのまま使います。なお、自動ダウンロード版はmacOS 12以降が必要です。古いmacOSやダウンロードに失敗した場合は、Homebrew / winget / Chocolatey / Scoop が使える環境ならそれを使ってインストールを試みます。

FFmpegは FFmpegプロジェクト のソフトウェアで、LGPL / GPLライセンスで配布されています。

元の音声ファイルは上書きされますか？

いいえ。元のファイルは残したまま、選んだ保存先フォルダに サークル名 / 作品名 の構成で新しく書き出します。

無料で使えますか？

はい。MITライセンスのオープンソースソフトとして無料で公開しています。

対応しているOSを教えてください

配布しているビルドは、macOS（Apple Silicon）と Windows（64-bit）向けです。なお、FFmpegの自動ダウンロードは macOS 12 以降に対応しています。

音声ファイルやタグ情報は外部に送信されますか？

送信されません。解析・編集・保存はすべてお使いのパソコン内だけで完結します。詳しくはプライバシーポリシーをご覧ください。
